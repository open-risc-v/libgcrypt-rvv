# libgcrypt G3：RISC-V 向量路径功能验收（2026-11-14）

上游 1.12.5 已带 RISC-V 汇编/向量实现，configure 用内联汇编探测决定是否启用：

```
cipher/chacha20-riscv-v.c        cipher/poly1305-riscv-v.c
cipher/chacha20-riscv-zvkb.c     cipher/rijndael-riscv-zvkned.c
cipher/rijndael-vp-riscv-mf2/4/8.c
cipher/cipher-gcm-riscv-zbb-zbc.c  cipher/crc-riscv-zbb-zbc.c
cipher/sha{1,256,512}-riscv-zvk*.c  cipher/sm3/sm4-riscv-zvk*.c
```

| 侧 | 配置 |
|---|---|
| A | 默认（探测到 riscv64 向量汇编即启用），`-march=rv64gcv` |
| B | `--disable-asm`，同一 `-march=rv64gcv` |

| 项 | A | B |
|---|---|---|
| sha256 + AES-CTR | `sha256=8ae5324f… fnv_ct=1b61c683d7e61c03` | 同左 |

逐字节一致（与 G2 基线值相同）。A 侧编译日志确认确实编进了
`chacha20-riscv-v.c`、`poly1305-riscv-v.c` 等向量源文件，不是"开了开关但走了 C 路径"。

注意：`rijndael-riscv-zvkned.c` 需要 `-march` 带 `zvkned`，本轮口径用基线 `rv64gcv`，
AES 仍走 C/其它路径。若板上支持 Zvkned，可另起一轮 `rv64gcv_zvkned_zvkb` 口径对比。

真机性能：`build/rvv-k/{on,off}/bench`（SHA-256 16 MiB + AES-256-CTR 16 MiB）。
